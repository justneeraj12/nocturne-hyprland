NOCTURNE / HYPRLAND — QUICK GUIDE
=================================

REMEMBER ONLY THESE THREE
  Super + Space           Find and launch any app
  Super + R               Open/toggle Nocturne Settings
  Super + Shift + R       Open the graphical resource monitor
  Super + /               Reopen this guide at any time

EVERYDAY APPS
  Super + Enter           Terminal
  Super + E               Files
  Super + B               Browser
  Super + C               ChatGPT
  Super + D               VS Code
  Super + T               Steam
  Super + N               Notification history
  Super + Shift + V       Clipboard history
  Super + W               Choose or restore a wallpaper
  Super + Escape          Lock screen
  Super + P               Power / log out

WINDOWS — NO GIANT WINDOW BUTTONS
  Super + Q               Close focused window
  Super + M               Minimize focused window
  Super + Shift + M       Pick a minimized window to restore
  Super + F               Fullscreen
  Super + Shift + F       Maximize while keeping the bar
  Super + A               Snap a floating app into the layout
  Super + V               Toggle floating
  Super + H/J/K/L         Focus left/down/up/right
  Super + Shift + H/J/K/L Move window in the layout
  Super + left-drag       Move a window with the mouse
  Super + right-drag      Resize a window with the mouse
  Alt + Tab               Cycle windows

STEAM + ODD APP WINDOWS
  Super + T               Open Steam, or jump to it if it is already open
  Steam's main library    Tiles with everything else automatically
  Settings / properties  Float centered so they do not wreck the layout
  Super + A               Fix any app that unexpectedly opens floating
  Super + Shift + 1…9     Send the focused app to another workspace

WORKSPACES
  Super + 1…9             Switch workspace
  Super + Shift + 1…9     Send a window to a workspace
  Super + mouse wheel     Cycle workspaces
  Three-finger swipe      Switch workspaces
  Super + S               Show/hide the scratchpad
  Super + Shift + S       Send a window to the scratchpad

TERMINAL BASICS
  Ctrl + Shift + C / V    Copy / paste
  Ctrl + L                Clear the screen
  Ctrl + C                Stop the running command
  Tab                     Complete a file or command name
  Up / Down               Browse command history
  exit                    Close the shell
  nocturne-dashboard      Open the full resource monitor

  intentionally minimal so Wi-Fi and Bluetooth are not duplicated.

MEDIA

FALLBACK
  Log out with Super + P and choose Ubuntu from the login-screen gear to return
  to the untouched GNOME macOS setup.
