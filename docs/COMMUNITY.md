# Community

Nocturne welcomes bug reports, hardware results, focused features, documentation
and visual presets. Discussions are the right place for questions and early
ideas; issues are reserved for reproducible work.

## Useful contributions

- run the dry installer in a disposable account or VM;
- submit a hardware compatibility report;
- reproduce a bug on a second machine;
- improve distribution-specific dependency mappings;
- contribute a palette or lock composition without weakening authentication;
- test keyboard-only, scaling and multi-monitor behaviour.

Do not include SSIDs, account names, window titles, clipboard contents, private
file names or unreviewed logs. `nocturne-support` creates a deliberately limited
archive, but contributors must still review it before uploading.

## Project decisions

Changes are judged against four constraints: coherent UX, authoritative Linux
services, bounded idle cost and reversible failure. A polished screenshot is not
enough if the interaction cannot be maintained or recovered safely.

Community packages contain no telemetry. Download counts shown by the project
come from the distribution edge or GitHub and are not measurements of active
desktops.
