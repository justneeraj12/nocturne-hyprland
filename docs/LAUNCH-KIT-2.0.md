# NOC 2.0 Alpha 1 launch kit

These are drafts for the maintainer to adapt, not instructions to cross-post the
same text everywhere.

## GitHub announcement

**Title:** NOC 2.0 Alpha 1 — encrypted continuity and a real community boundary

> NOC is growing from my personal Hyprland setup into an installable desktop
> platform. Alpha 1 keeps Hyprland as the compositor and adds the product pieces
> around it: one native Qt shell, Settings, supervised session services,
> rollback, encrypted multi-device continuity and a documented hardware matrix.
>
> The Community desktop does not phone home. A separate private operator system
> can count download redirects by country/release, but the package has no
> endpoint or device identifier and the project does not claim active-user
> numbers.
>
> I am looking for Ubuntu 26.04 testers—especially AMD, mixed-scale and 3+
> display systems. Please use a disposable account first and report hardware
> through the repository form.
