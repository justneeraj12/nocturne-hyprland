# Nocturne 1.3 — Signal Identity

Nocturne 1.3 expands personalization without forking critical system behavior.
All ten lock compositions render through one Hyprlock configuration pipeline and
one PAM-backed authentication path.

## Lock compositions

Editorial, Center Signal, NOC Grid, Phosphor Terminal and Relay Split are joined
by Black Ice, Red Sector, Signal Tower, Mainframe and Dead Channel. Each keeps
password feedback, Caps Lock state, active accent, media and machine context.

Wallpaper treatment is independently selectable as Void, Dim, Balanced or
Vivid. Clock notation is independently selectable as Operator (`+` AM / `−`
PM), conventional 12-hour or 24-hour. Existing lock state migrates in place.

## Terminal identity

Fastfetch now carries a framed wide NOC wordmark. `nocturne-banner` uses the same
active accent, automatically switches to a compact mark for narrow splits and
can append live node, session and uptime state without a resident process.

## Reliability

The release contract renders all ten templates, rejects unresolved palette
tokens, exercises every customization value, validates private state permissions
and keeps the existing one-unlock preview rollback behavior.
